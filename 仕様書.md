# Meltype MC Specification (English)

Last updated: 2026-10-24 / Target version: 1.0.7

*日本語版は、このファイルの下にあります（[日本語版へ移動](#meltype-mc-仕様書日本語)）。*

Meltype MC is a client-side-only Minecraft (Fabric) mod. It lets you type Japanese (romaji input) and English (commands, item names, and so on) mixed together, without switching with the Hankaku/Zenkaku key. The idea of automatically telling English and Japanese apart is ported from "Meltype" by Yukishiro.

---

## 1. Requirements

| Item | Details |
| :--- | :--- |
| Minecraft | 26.1 or later (developed and tested on 26.2) |
| Mod loader | Fabric Loader 0.19.0 or later |
| Java | 25 or later |
| Required mods | Fabric API (`fabric-screen-api-v1`), Fabric Language Kotlin |
| Optional mod | Mod Menu (if installed, the "Settings" button in the mod list opens the settings screen; the mod works without it) |
| Runs on | Client only (you do not need to install it on the server) |
| License | GPL-3.0 |
| OS | Windows / Mac / Linux (no external app has to keep running) |

## 2. Overview and Design Policy

- Keyboard events (keys and characters) are received through the Fabric Screen API. Minecraft's vanilla handling is cancelled only for the input that the mod handles itself.
- No Mixins are used, so the mod is resistant to Minecraft updates.
- Only the confirmed Japanese text is inserted into the chat box and other fields.
- Text that is still being converted is handled outside the input field (in Meltype's internal buffer and in an underlined preview drawn above the field), not inside the field. If unconfirmed text were placed in the field, other mods (for example Chat Patches' draft saving or command suggestions) could read it before it is confirmed. Because of this, converting inside the input field is deliberately not supported.
- If an exception occurs, the mod hands control back to vanilla handling (it must never break the game).

## 3. Supported Screens

| Screen | Description |
| :--- | :--- |
| Chat (`ChatScreen`) | Normal chat and command input |
| Anvil (`AnvilScreen`) | Item name input |
| Sign editing (`AbstractSignEditScreen`) | Typing text on signs |
| Book and quill (`BookEditScreen`) | Writing and signing books |
| Others | Any screen that has a focused input field (`EditBox`) |

## 4. Input Modes

| Mode | Display | Behavior |
| :--- | :--- | :--- |
| HYBRID (Japanese conversion) | `あ/A` | Automatically tells English and Japanese apart (default) |
| DIRECT (half-width alphanumeric) | ` A ` | The mod does not interfere at all; vanilla input as is |

- The mode when a screen opens follows the "Initial mode" setting. If "Remember last mode" is ON, the previous mode is kept across screens.
- When you switch modes, any text being typed is confirmed first.

## 5. Input Flow (HYBRID mode)

1. **Slash check (highest priority)**: typing `/` in an empty chat box starts command mode, and the mod is bypassed for as long as the text starts with `/`. Exceptions: for `/me`, `/say`, and `/tell`, `/msg`, `/w`, `/whisper` (after the recipient), Japanese input comes back for the message part.
2. **Letters and hyphen**: collected in the input buffer (`rawBuffer`) and shown as an underlined preview. If you type a letter while candidates are showing, the previous candidate is confirmed first and a new word starts.
3. **Space**: decides the input type and converts it (see 6). If candidates are showing, moves to the next candidate.
4. **Punctuation and symbols while typing**: `,` `.` `?` `!` `~` `～` `〜` are added to the buffer as `、` `。` `？` `！` `～`.
   - If you type one after converting (candidates showing), the selected candidate is confirmed first, and then the symbol is entered.
5. **`~` when not typing**: enters the full-width `～` as it is.
6. **Confirmed characters arriving from an external Japanese input method (such as Windows IME)**: the mod discards its own unconfirmed buffer and passes that character to vanilla as it is (to prevent double input).
7. **Any other symbols and digits**: if you are typing, the current candidate is confirmed first, and then the character is entered.

## 6. Conversion and Candidates

### 6.1 Telling English and Japanese Apart (`ScoreEngine`)

- These are treated as English:
  - Words of 3 or more letters that exactly match the English dictionary (about 10,000 words), for example `diamond`. However, everyday Japanese words (such as `sore`, `are`, `dare`, `sake`, `arigatou`) are treated as Japanese first.
  - Letter sequences that cannot be romaji (for example `minecraft`, `modrinth`).
  - Letter sequences that contain capital letters (for example `Modrinth`).
- Valid romaji of 1 to 2 letters (such as `ha`, `to`, `no`) is treated as Japanese.
- Everything else is scored by romaji characteristics (small kana, double consonants, long vowels, syllable count). The Japanese-detection threshold can be changed in the settings (default 2; the larger it is, the more likely the input is treated as English).

### 6.2 Conversion Types (`ConversionPlanner`)

| Type | Example | Result |
| :--- | :--- | :--- |
| Sentence separated by spaces | `kyouha diamond wo sagasou` | 今日は diamond を探そう |
| English and Japanese mixed | `kyouhadiamondwotoriniikou` | 今日はdiamondを取りに行こう |
| English word + particle compound | `diamondwosagasou` | diamondを探そう |
| Single word | `kyouha` | 今日は |

- English and Japanese are split using particles (を, が, は, の, に, で, と, も, へ, て, ...) as clues.
- If the whole input can be read as romaji from start to end, English words of 4 letters or fewer are not picked out of it (so that, for example, `hidarite`, `settei`, and `onegaishitai` are not mistaken for English).

### 6.3 Conversion Candidates

- Candidates come in two stages: immediate candidates (shown without waiting for the network) and final candidates (after the conversion result arrives).
- For a single word (Japanese-leaning), the final order is: learned candidates → Google's conversion results → hiragana → katakana → the letters exactly as typed.
- For English-leaning input, the letters as typed are the first candidate.
- **The letters as typed and the hiragana always stay inside the candidate list limit.**
- The maximum number of candidates shown is 7 or 9 (setting). Number keys 1 to 9 select a candidate directly.

### 6.4 Conversion Learning (`ConversionLearningStore`)

- Each time you confirm a candidate, the mod records how many times that reading/candidate pair was confirmed and when it was last used.
- From then on, candidates are put first in order of count (most recent first when counts are equal).
- Can be turned ON/OFF in the settings. The history can be cleared from the settings screen.

### 6.5 Resizing the Clause (`ClauseManager`)

- `Shift + ←` shrinks the part being converted by one character from the end, and `Shift + →` extends it.
- The display is `[clause being converted]remaining unconfirmed text`.
- If you confirm while it is shortened, only that clause is entered, and the rest goes back into the buffer as the next input.

### 6.6 Romaji Input (`RomajiDetector`)

- A single `n` at the end of a word (for example `harowin`) becomes "ん" when you convert or confirm. While you are still typing, the preview keeps it as "n" (because an `a` might follow).
- Besides the basic table, these are supported: `wi` / `wu` / `wha` `whi` `whu` `whe` `who` (ウィ…), `ye`, `zya` `zyu` `zye` `zyo`, `cya` `cyu` `cye` `cyo`, `tsa` `tsi` `tse` `tso`, `tha` `thu` `the` `tho`, `dha` `dhu` `dhe` `dho`, `kwa` `kwi` `kwu` `kwe` `kwo`, `gwa` `gwi` `gwu` `gwe` `gwo`.
- `we` is not converted to "うぇ" because it is a common English word (type `whe` instead).

## 7. Key Operations

### 7.1 Switching the Mode

| Operation | Action |
| :--- | :--- |
| Hankaku/Zenkaku key (the key with the backquote `` ` ``, JIS scan code 41) | Toggle HYBRID ⇔ DIRECT |
| Ctrl + Space | Same as above (the space character that follows is discarded, so no space is typed) |
| Henkan key | Switch to HYBRID |
| Muhenkan key | While typing: cycle hiragana → katakana → letters. When not typing: switch to DIRECT |
| A registered toggle key | Same as above (you can register any key in the settings screen; see 7.3) |
| Left-click the icon (`あ/A` in the chat box) | Toggle HYBRID ⇔ DIRECT |
| Right-click the icon | Open the settings screen |
| "Settings" button in Mod Menu (the mod list screen) | Open the settings screen. Works even if the icon is hidden (when Mod Menu is installed) |

### 7.2 Keys While Typing

| Key | Action |
| :--- | :--- |
| Space | Convert. If candidates are showing, go to the next candidate |
| Shift + Space | Add a half-width space to the buffer (to keep typing a sentence) |
| Enter | Confirm the selected candidate (or the preview if there is none) |
| Shift + Enter | Confirm the letters exactly as first typed |
| Backspace | Close the candidates, or delete one character |
| Esc | Cancel the conversion |
| Tab / Shift + Tab | Next / previous candidate (starts the conversion if no candidates are showing) |
| ← → ↑ ↓ | Select a candidate (↓ starts the conversion if no candidates are showing) |
| Shift + ← / → | Shrink / extend the clause |
| 1 to 9 (including the numpad) | Pick a candidate directly and confirm it |
| F6 | Convert to hiragana |
| F7 | Convert to katakana |
| F9 | Convert to full-width alphanumeric |
| F10 | Half-width alphanumeric (as typed) |
| Shift + F12 | Enter a full-width `～` |

### 7.3 Registering a Toggle Key

- Press the "Toggle key" button in the settings screen, then press the key you want to register. `Esc` clears it.
- Letter, digit, and symbol keys can only be registered together with `Ctrl` or `Alt` (so that you do not lose the ability to type them). If you press a key that cannot be registered, the screen shows why.
- Enter, Tab, Backspace, the arrow keys, and Shift / Ctrl / Alt alone cannot be registered.

## 8. On-Screen Display (`CompositionRenderer`, `IndicatorLayout`)

| Part | Details |
| :--- | :--- |
| Mode icon | `あ/A` (Japanese conversion) / ` A ` (half-width alphanumeric). Size 26×12. A tooltip appears on hover |
| Candidate window | In the form `▶ 1. 今日は  2. 京葉 …`. The selected candidate is highlighted in orange and blue |
| Underlined preview | `変換中: …` ("Converting: …"). When the clause is shortened, it looks like `[clause]rest` |
| Icon position | Chat: left end of the input field. Anvil: near the input field. Sign: just left of the "Done" button. Book: just left of the "Sign" button |

- The start of the chat input field is shifted to the right so that it does not overlap the icon.
- The position of the candidate window is adjusted so that it does not overlap parts of other mods (such as Chat Patches' search bar).

## 9. Settings

Open the settings screen by right-clicking the icon in the chat box, or from the "Settings" button in Mod Menu (when you have hidden the icon, open it from Mod Menu). Settings are saved to `.minecraft/config/meltype/config.properties` (UTF-8).

| Setting key | Name on screen | Default | Description |
| :--- | :--- | :--- | :--- |
| `enabled` | (not on screen) | `true` | Enable / disable the mod |
| `maxCandidates` | Number of candidates | `7` | 7 or 9 |
| `initialInputMode` | Initial mode | `HYBRID` | Mode when a screen opens |
| `rememberLastInputMode` | Keep last mode | `true` | Remember across screens |
| `showModeIndicator` | Chat box icon | `true` | Show / hide the icon |
| `autoCommandModeOnSlash` | Release IME for commands | `true` | Automatically bypass on `/` |
| `learningEnabled` | Conversion learning | `true` | Enable / disable learning |
| `useGoogleCgi` | Google conversion | `true` | `false` converts with the built-in dictionary only, with no network access |
| `japaneseThreshold` | Japanese-detection threshold | `2` | 1 to 4; the larger it is, the more likely input is treated as English |
| `toggleKeyCode` / `toggleKeyModifiers` | Toggle key | `-1` / `0` | The registered key (-1 means not set) |

## 10. Data and Network

| Item | Details |
| :--- | :--- |
| Learning data | `.minecraft/config/meltype/learned_words.txt` |
| Settings | `.minecraft/config/meltype/config.properties` |
| Network access | By default, the hiragana reading being converted is sent to Google's Japanese Input transliteration service (`https://www.google.com/transliterate`). Only the reading is sent; the player name and server information are not. The timeout is about 1 second. Up to 1,000 conversion results are cached |
| Turning network access off | Turn "Google conversion" OFF in the settings to convert with the built-in dictionary only, with no network access |
| When the network is unavailable | The mod automatically falls back to the built-in dictionary (`LocalDictionaryConverter`: greetings, particles, common words, plus hiragana and katakana) |

## 12. Build and Tests

- Build: `gradlew build` (Gradle Kotlin DSL, Kotlin 2.4.20, JDK 25). The build needs jars such as Minecraft, Fabric, and Mod Menu (`modmenu-20.0.1.jar`) in the `libs/` folder (`libs/` is not kept in Git). Mod Menu is used only while building and is not included in the jar.
- Tests: JUnit 5, 55 tests (input flow, conversion, candidates, learning, settings, toggle key, and so on), split into files by theme.
- The build is set up so that no build date is left in the jar (`isPreserveFileTimestamps = false`, `isReproducibleFileOrder = true`).

## 13. Known Issues

- Earlier, the same word could be typed twice, and the first character right after opening the chat could be lost. The cause was that a conversion result arriving late was applied to the next word you had already started typing; this is now prevented with a generation number (1.0.6). It has not reproduced in real-world use, but because it only "sometimes" happened, we keep watching it.
- Mixing a short English word (4 letters or fewer) into the middle of romaji (for example `ice` in `kyouhaicewotoru`) is not split out as English (it works if you separate it with a space).
- Does not work on versions before 26.1, such as Minecraft 1.21.

# Meltype MC 仕様書（日本語）

最終更新: 2026-10-24 ／ 対象バージョン: 1.0.7

*English version is above (at the top of this file).*

Meltype MC は、Minecraft（Fabric）のクライアント専用MODです。［半角/全角］キーで切り替えずに、日本語（ローマ字入力）と英語（コマンド・アイテム名など）を混ぜて打てる入力システムを提供します。Yukishiro 氏の「Meltype」の英日自動判別の考え方を移植したものです。

---

## 1. 動作環境

| 項目 | 内容 |
| :--- | :--- |
| Minecraft | 26.1 以降（開発・動作確認は 26.2） |
| MODローダー | Fabric Loader 0.19.0 以降 |
| Java | 25 以降 |
| 依存MOD | Fabric API（`fabric-screen-api-v1`）、Fabric Language Kotlin |
| あると便利なMOD | Mod Menu（入っていれば、MOD一覧の「設定」ボタンから設定画面を開ける。なくても動く） |
| 実行側 | クライアント専用（サーバーに入れる必要はありません） |
| ライセンス | GPL-3.0 |
| OS | Windows / Mac / Linux（外部アプリの常駐は不要） |

## 2. 概要と設計方針

- 画面の入力イベント（キー・文字）を Fabric Screen API で受け取り、MODが処理した分だけバニラ（Minecraft標準）の処理を止める。
- 内部の書き換え（Mixin）を使わないので、Minecraft の更新に強い。
- 日本語入力の確定文字だけを、チャット欄などへ挿入する。
- 変換中の文字は、入力欄の中ではなく、入力欄の外（Meltype の内部のバッファと、入力欄の上の下線付きプレビュー）で処理する。入力欄の中に確定前の文字を置くと、ほかのMOD（Chat Patches の下書き保存、コマンド補完など）が確定前の文字を読んでしまうため。入力欄の中で変換する方式は、この理由で採用しない。
- 例外が起きたときは、バニラの標準処理にそのまま任せる（ゲームを壊さない）。

## 3. 対応する画面

| 画面 | 説明 |
| :--- | :--- |
| チャット（`ChatScreen`） | 通常のチャット欄・コマンド入力 |
| 金床（`AnvilScreen`） | アイテム名の入力 |
| 看板編集（`AbstractSignEditScreen`） | 看板への文字入力 |
| 本と羽根ペン（`BookEditScreen`） | 本の執筆・署名 |
| その他 | フォーカス中の入力欄（`EditBox`）を持つ画面 |

## 4. 入力モード

| モード | 表示 | 動作 |
| :--- | :--- | :--- |
| HYBRID（日本語変換） | `あ/A` | 英日を自動判別して打ち分ける（初期設定） |
| DIRECT（半角英数） | ` A ` | MODは一切介入せず、バニラの入力のまま |

- 画面を開いたときのモードは、設定の「初期モード」に従う。「前回のモードを維持」が ON なら、画面をまたいで前回のモードを保つ。
- モードを切り替えたとき、入力途中の文字があれば確定してから切り替える。

## 5. 入力の流れ（HYBRID モード）

1. **スラッシュ判定（最優先）**: チャット欄が空のときに `/` を打つと、コマンドモードになり、MODをバイパスする。先頭が `/` のあいだはずっとバイパス。ただし `/me`、`/say`、`/tell`・`/msg`・`/w`・`/whisper`（宛先のあと）は、メッセージ部分で日本語入力に戻る。
2. **英字・ハイフン**: 入力バッファ（`rawBuffer`）にためて、下線付きのプレビューを表示する。候補が出ているときに英字を打つと、前の候補を確定してから新しい単語を始める。
3. **Space**: 判定して変換する（6. 参照）。候補が出ているときは次の候補へ進む。
4. **句読点・記号（入力中）**: `,` `.` `?` `!` `~` `～` `〜` は、`、` `。` `？` `！` `～` としてバッファに足す。
   - 候補が出ている状態（変換後）で打った場合は、選択中の候補を確定してから、記号を続けて入力する。
5. **入力中でないときの `~`**: 全角の `～` をそのまま入力する。
6. **外部の日本語入力（Windows IME など）から確定文字が届いた場合**: MODの入力途中のバッファを捨てて、その文字はバニラにそのまま渡す（二重入力の防止）。
7. **それ以外の記号・数字**: 入力中なら、いまの候補を確定してから、その文字を入れる。

## 6. 変換の判定と候補

### 6.1 英語か日本語かの判定（`ScoreEngine`）

- 次のものは英語にする。
  - 3文字以上で、英単語辞書（約1万語）に完全一致する語（例: `diamond`）。ただし、日本語の日常語（`sore`、`are`、`dare`、`sake`、`arigatou` など）は日本語を優先する。
  - ローマ字として成立しない並び（例: `minecraft`、`modrinth`）。
  - 大文字を含む英字列（例: `Modrinth`）。
- 1〜2文字で有効なローマ字（`ha`、`to`、`no` など）は日本語にする。
- そのほかは、ローマ字の特徴（拗音・促音・長音・音節数）を点数にして判定する。日本語の判定のしきい値は設定で変えられる（初期値 2。大きいほど英語になりやすい）。

### 6.2 変換の種類（`ConversionPlanner`）

| 種類 | 例 | 結果 |
| :--- | :--- | :--- |
| スペース区切りの文 | `kyouha diamond wo sagasou` | 今日は diamond を探そう |
| 英語と日本語の混在 | `kyouhadiamondwotoriniikou` | 今日はdiamondを取りに行こう |
| 英単語＋助詞の複合語 | `diamondwosagasou` | diamondを探そう |
| 単一の単語 | `kyouha` | 今日は |

- 英語と日本語の分割は、助詞（を・が・は・の・に・で・と・も・へ・て など）を手がかりにする。
- 入力全体がローマ字として最後まで読める場合は、4文字以下の英単語を取り出さない（例: `hidarite`、`settei`、`onegaishitai` が英語と間違われないようにするため）。

### 6.3 変換候補

- 候補は、すぐ出す候補（通信を待たない）と、変換結果が届いたあとの最終候補の2段階。
- 単一の単語（日本語寄り）の最終候補の並びは、学習した候補 → Google の変換結果 → ひらがな → カタカナ → 打った英字そのまま。
- 英語寄りの場合は、打った英字を第1候補にする。
- **打った英字そのままと、ひらがなは、必ず候補の枠内に残す。**
- 候補の最大表示数は 7 個または 9 個（設定）。数字キー 1〜9 で直接選べる。

### 6.4 変換の学習（`ConversionLearningStore`）

- 候補を確定するたびに、読みと候補の組み合わせの確定回数と最終使用時刻を記録する。
- 次回から、回数の多い順（同数なら新しい順）に、候補の先頭へ並べる。
- 設定で ON/OFF できる。設定画面から履歴を消せる。

### 6.5 文節の伸び縮み（`ClauseManager`）

- `Shift + ←` で、変換する範囲を末尾から1文字ずつ縮め、`Shift + →` で伸ばす。
- 表示は `[変換中の文節]残りの未確定文字列`。
- 縮めた状態で確定すると、その文節だけが入力され、残りは次の入力としてバッファに戻る。

### 6.6 ローマ字の入力（`RomajiDetector`）

- 語尾に `n` を1つだけ打った語（例: `harowin`）は、変換・確定のときに「ん」になる。入力途中のプレビューでは、次に `a` などが続くかもしれないため、`n` のままにしている。
- 基本の表のほかに、次を打てる: `wi` / `wu` / `wha` `whi` `whu` `whe` `who`（ウィ…）、`ye`、`zya` `zyu` `zye` `zyo`、`cya` `cyu` `cye` `cyo`、`tsa` `tsi` `tse` `tso`、`tha` `thu` `the` `tho`、`dha` `dhu` `dhe` `dho`、`kwa` `kwi` `kwu` `kwe` `kwo`、`gwa` `gwi` `gwu` `gwe` `gwo`。
- `we` は、英単語の `we` と同じなので、「うぇ」には変換しない（「うぇ」は `whe` で打つ）。

## 7. キー操作

### 7.1 モードの切り替え

| 操作 | 動作 |
| :--- | :--- |
| 半角/全角キー（バッククォート ` のキー、JIS のスキャンコード41） | HYBRID ⇔ DIRECT を切り替え |
| Ctrl + Space | 同上（続けて届く空白の文字は捨てるので、空白は入らない） |
| 変換キー | HYBRID にする |
| 無変換キー | 入力中: ひらがな → カタカナ → 英字を順に切り替え。入力中でなければ DIRECT にする |
| 登録した切り替えキー | 同上（設定画面で好きなキーを登録できる。7.3 参照） |
| アイコン（チャット欄の `あ/A`）を左クリック | HYBRID ⇔ DIRECT を切り替え |
| アイコンを右クリック | 設定画面を開く |
| Mod Menu（MODの一覧画面）の「設定」ボタン | 設定画面を開く。アイコンを非表示にしていても使える（Mod Menu が入っているとき） |

### 7.2 入力中の操作

| キー | 動作 |
| :--- | :--- |
| Space | 変換する。候補が出ているときは次の候補へ |
| Shift + Space | バッファに半角スペースを足す（文を続けて入力） |
| Enter | 選択中の候補（なければプレビュー）を確定 |
| Shift + Enter | 最初に打った英字そのままで確定 |
| Backspace | 候補を閉じる、または1文字削除 |
| Esc | 変換をキャンセル |
| Tab / Shift + Tab | 候補を進める／戻す（候補がなければ変換を始める） |
| ← → ↑ ↓ | 候補の選択（↓ は候補がなければ変換を始める） |
| Shift + ← / → | 文節を縮める／伸ばす |
| 1〜9（テンキー含む） | 候補を直接選んで確定 |
| F6 | ひらがなにする |
| F7 | カタカナにする |
| F9 | 全角英数にする |
| F10 | 半角英数（打ったまま）にする |
| Shift + F12 | 全角の `～` を入力 |

### 7.3 切り替えキーの登録

- 設定画面の「切り替えキー」を押して、登録したいキーを押す。`Esc` で解除。
- 文字・数字・記号キーは、`Ctrl` か `Alt` と組み合わせたときだけ登録できる（打てなくなるのを防ぐため）。登録できないキーを押すと、理由が画面に出る。
- Enter、Tab、Backspace、矢印キー、Shift・Ctrl・Alt 単体は登録できない。

## 8. 画面表示（`CompositionRenderer`、`IndicatorLayout`）

| 部品 | 内容 |
| :--- | :--- |
| モード切替アイコン | `あ/A`（日本語変換）／ ` A `（半角英数）。大きさは 26×12。ホバーで説明を表示 |
| 変換候補ウィンドウ | `▶ 1. 今日は  2. 京葉 …` 形式。選択中の候補をオレンジ・青でハイライト |
| 下線付きプレビュー | `変換中: …`。文節を縮めたときは `[文節]残り` の形 |
| アイコンの位置 | チャット: 入力欄の左端。金床: 入力欄の近く。看板: 「完了」ボタンの左隣。本: 「署名」ボタンの左隣 |

- チャット欄の入力開始位置は、アイコンと重ならないよう右にずらす。
- 他のMOD（Chat Patches の検索バーなど）の部品と重ならないよう、候補ウィンドウの位置を調整する。

## 9. 設定

設定画面は、チャット欄のアイコンを右クリックするか、Mod Menu の「設定」ボタンから開く（アイコンを非表示にしたときは、Mod Menu から開く）。保存先は `.minecraft/config/meltype/config.properties`（UTF-8）。

| 設定キー | 画面での名前 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| `enabled` | （画面なし） | `true` | MODの有効／無効 |
| `maxCandidates` | 変換候補の表示数 | `7` | 7 または 9 |
| `initialInputMode` | 初期モード | `HYBRID` | 画面を開いたときのモード |
| `rememberLastInputMode` | 前回のモードを維持 | `true` | 画面をまたいで記憶 |
| `showModeIndicator` | チャット欄アイコン | `true` | アイコンの表示／非表示 |
| `autoCommandModeOnSlash` | コマンド時IME解除 | `true` | `/` で自動的にバイパス |
| `learningEnabled` | 変換学習機能 | `true` | 学習の有効／無効 |
| `useGoogleCgi` | Google変換 | `true` | `false` で外部通信をせず、内蔵辞書のみで変換 |
| `japaneseThreshold` | 日本語判定のしきい値 | `2` | 1〜4。大きいほど英語になりやすい |
| `toggleKeyCode` / `toggleKeyModifiers` | 切り替えキー | `-1` / `0` | 登録したキー（-1 は未設定） |

## 10. データと通信

| 項目 | 内容 |
| :--- | :--- |
| 学習データ | `.minecraft/config/meltype/learned_words.txt` |
| 設定 | `.minecraft/config/meltype/config.properties` |
| 外部通信 | 初期設定では、変換中のひらがなを Google 日本語入力の変換サービス（`https://www.google.com/transliterate`）へ送る。送るのは読みだけで、プレイヤー名やサーバー情報は送らない。タイムアウトは約1秒。変換結果は最大1000件までキャッシュする |
| 通信しない設定 | 設定の「Google変換」を OFF にすると、通信せず内蔵辞書だけで変換する |
| 通信できないとき | 自動で内蔵辞書（`LocalDictionaryConverter`：挨拶・助詞・よく使う語＋ひらがな・カタカナ）に切り替える |

## 12. ビルドとテスト

- ビルド: `gradlew build`（Gradle Kotlin DSL、Kotlin 2.4.20、JDK 25）。ビルドには、`libs/` フォルダに Minecraft・Fabric・Mod Menu（`modmenu-20.0.1.jar`）などの jar が必要（`libs/` は Git に入れていない）。Mod Menu は、ビルドのときだけ使い、jar には含めない。
- テスト: JUnit 5、55件（入力の流れ、変換、候補、学習、設定、切り替えキーなど）。テーマごとに複数のファイルに分けてある。
- jar にビルド日時を残さない設定（`isPreserveFileTimestamps = false`、`isReproducibleFileOrder = true`）を入れている。

## 13. 既知の課題

- 以前、**同じ言葉が2回入る**、**チャットを開いた直後の1文字目が抜ける**ことがあった。変換結果が遅れて届いたとき、確定後に打ち始めた次の単語に古い結果が入り込むことが原因で、世代番号で防ぐようにした（1.0.6）。実機の試用では再現していないが、「たまに起きる」不具合のため、引き続き様子を見る。
- 短い英単語（4文字以下）を、ローマ字の途中に混ぜて打つ入力（例: `kyouhaicewotoru` の `ice`）は、英語として分けられない（スペースで区切れば使える）。
- Minecraft 1.21 系など、26.1 より前の版では動かない。

# Meltype MC v1.0.8 — Changelog / 更新内容

## English

**New**
- Telling others a command: if you start a chat message with `#/` (for example `#/tp 100 64 100`), the leading `#` is removed when the message is sent, so everyone sees `/tp 100 64 100`. It is sent as a normal chat message, not as a command, so it never runs by accident. Only a `#` right before a leading `/` is removed (`#//br smooth` becomes `//br smooth`).
- You can turn this off with the new button "発言の先頭の #/ の # を外す" in the settings screen (on by default). When it is off, the message is sent exactly as you typed it.

**Fixes**
- `motto` (もっと) and `dame` (だめ) are now treated as Japanese. Before, they were mistaken for the English words "motto" and "dame" and could not be converted.

**Notes**
- This uses the Fabric Message API (`fabric-message-api-v1`), which is part of Fabric API, so you do not need to install anything extra.
- Some servers or chat plugins may change messages that start with `#/` on their own. The mod itself sends the message exactly as set above.

## 日本語

**新機能**
- コマンドを人に伝えるときの機能です。チャットの発言の先頭に `#/` を付けて（例: `#/tp 100 64 100`）送ると、送信するときに、先頭の「#」が外れて、みんなに `/tp 100 64 100` と見えます。コマンドではなく、普通の発言として送られるので、うっかり実行されることはありません。外すのは、先頭の `/` の直前の「#」だけです（`#//br smooth` は `//br smooth` になります）。
- 設定画面の新しいボタン「発言の先頭の #/ の # を外す」で、この機能を OFF にできます（初期設定は ON）。OFF のときは、打ったとおりに、そのまま送ります。

**修正**
- `motto`（もっと）と `dame`（だめ）が、英単語の「motto」「dame」と間違われて、変換できなかった問題を直しました。日本語として扱います。

**メモ**
- Fabric API に含まれる Fabric Message API（`fabric-message-api-v1`）を使っているので、新しく入れるものはありません。
- サーバーやチャット系のプラグインが、`#/` で始まる発言を、独自に書き換えることがあります。MODは、上に書いたとおりに送ります。

# Meltype MC (Fabric Client Mod)

<p align="center">
  <img src="icon.png" width="128" height="128" alt="Meltype MC Icon">
</p>

**雪解けのように、マイクラから［半角/全角］キーの壁を溶かす日本語入力MOD。**

Meltype（雪代氏作）の英日自動判別アルゴリズムをMinecraft（Fabric）向けに移植したクライアント専用MODです。  
チャット欄でキーボードを切り替えることなく、日本語と英語（コマンド・アイテム名）をシームレスにタイピングできます。

---

## ✨ 主な特徴

1. **［半角/全角］キー不要のハイブリッド入力 ＆ 複合語自動分割**
   - キーボードを切り替える必要が一切ありません。
   - `kyouha diamond wo sagasou` とそのまま打つだけで、
     - `kyouha` → **今日は**（日本語判定）
     - `diamond` → **diamond**（英単語判定・英語のまま）
     - `wo` → **を**（日本語判定）
     - `sagasou` → **探そう**（日本語判定）
     と自動で打ち分けられます。
   - スペースを空けずに `diamondwosagasou` と打っても、英単語と助詞（てにをは）を自動認識して **「diamondを探そう」** に変換されます！

2. **スラッシュ（`/`）入力による自動コマンドモード切替**
   - チャット欄で `/` を打った瞬間、**自動的にコマンド直接入力モードに切り替わり、日本語IMEをバイパス**します。
   - `/gamemode creative` や `/tp @p ...` などのコマンド入力がIMEに邪魔されず、普段通りの英数タイピングが可能です。

3. **賢い「変換学習機能」**
   - よく選ぶ漢字や変換候補を自動で学習・記録します。
   - 次回同じ読みを入力した際、頻繁に使う変換候補が自動的にリストの最上位に表示されるため、打てば打つほど自分好みに使いやすくなります。

4. **チャット欄アイコン ＆ 専用設定メニュー (`Meltype Config`)**
   - チャット欄先頭に現在の入力モードを表すアイコン（`[ あ ]` / `[ A ]`）を表示。
   - **左クリック**: 半角英数（DIRECT）と日本語（HYBRID）をワンクリックで手動切替。
   - **右クリック**: 専用設定メニューが開き、以下の項目を自由にカスタマイズ可能：
     - 変換候補の表示数（3〜9個）
     - チャット開始時の初期モード
     - 前回入力モードの記憶・維持
     - アイコンの表示 / 非表示
     - コマンド時IME自動解除のON/OFF
     - 変換学習機能のON/OFF ＆ 学習履歴のクリア

5. **ゲーム内の主要テキスト入力画面にフル対応！**
   - **チャット画面 (`ChatScreen`)**
   - **金床画面 (`AnvilScreen`)**：アイテムの日本語名付け
   - **看板編集画面 (`AbstractSignEditScreen`)**：看板への文字入力
   - **本と羽根ペン画面 (`BookEditScreen`)**：長文の執筆・メモ

6. **ゲーム内インライン候補表示**
   - 各画面の入力欄に合わせて、マイクラ風の半透明背景で変換候補ウィンドウ（`[1] 今日は [2] 京葉 ...`）と下線プレビューが表示されます。
   - `Space` や `↑` / `↓` / `←` / `→` 方向キー（矢印キー）で候補を選択送り・戻し、`Enter` で確定、`1`〜`9` キーで直接ダイレクト選択が可能です。

7. **完全内蔵型（全OS対応）**
   - Windows, Mac, Linux すべてに対応。外部アプリの常駐や設定は不要です。
   - チャット・テキスト入力画面内でのみ動作するため、WASD移動などのゲーム操作に干渉しません。

## ⌨️ キー操作一覧

| キー | 動作 |
| :--- | :--- |
| **ローマ字入力** | そのまま入力（英日自動判別） |
| **`/` (先頭)** | コマンド直接入力モード（チャット時IMEバイパス） |
| **Space** | 漢字変換の実行 / 次の候補へ |
| **↑ / ↓ / ← / → (方向キー)** | 変換候補の選択送り / 戻し |
| **Tab / Shift+Tab** | 変換候補の選択送り / 戻し |
| **Enter** | 候補（または未確定文字）を確定して入力欄へ挿入 |
| **1 〜 9** | 該当番号の候補をダイレクト確定 |
| **Backspace** | 1文字削除（候補表示中は候補選択キャンセル） |
| **Escape** | 変換キャンセル |

# Meltype MC v1.0.5 — Changelog / 更新内容

## English

**Fixes**
- On the sign and book editing screens, the input-mode button now appears just to the left of the "Done" button (signs) or the "Sign" button (books), instead of low in the middle of the screen.

**Also included from v1.0.4**
- Clause resizing with `Shift + Left/Right Arrow`: shrink or extend the part being converted one character at a time. The preview shows it like `[today]hadiamond`.
- Partial confirmation: confirming a shortened clause inserts only that part, and the rest stays in the input buffer so you can keep converting.
- Internal cleanup for easier maintenance (no change in behavior).

**Requirements**
- Minecraft 26.1 or later, Fabric Loader 0.19.0 or later, Java 25 or later
- Fabric API and Fabric Language Kotlin

## 日本語

**修正**
- 看板と本の編集画面で、入力モード切り替えボタンが、画面中央の下のほうではなく、看板は「完了」ボタンの左、本は「署名」ボタンの左に表示されるようになりました。

**v1.0.4 の内容も含みます**
- `Shift + 左右矢印キー` で文節を伸び縮みできます。変換する範囲を1文字ずつ縮めたり伸ばしたりできます。プレビューには `[今日]はdiamond` のように表示されます。
- 部分確定: 縮めた文節を確定すると、その部分だけが入力され、残りは入力途中のまま残るので、続けて変換できます。
- 内部の整理を行いました（動作は変わりません）。

**必要なもの**
- Minecraft 26.1 以降、Fabric Loader 0.19.0 以降、Java 25 以降
- Fabric API と Fabric Language Kotlin
